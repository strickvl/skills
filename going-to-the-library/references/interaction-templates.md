# Interaction Templates

Adapt these structures rather than copying them mechanically. Keep citations beside the claims they support.

## A. First floor plan

```markdown
# Library card

**Subject:** ...
**Workbench problem:** ...
**Scope:** ...

## Questions that organize this field

1. ...
2. ...
3. ...

# Floor plan

## Shelf 1: [Name]
**Guiding question:** ...
**Why it matters:** ...

**Start here: Creator, _Title_ (year)** · [doorway; current standing: strong]
**Why it is here:** ...

**Creator, _Title_ (year)** · [foundation; current standing: mixed]
**Why it is here:** ...

[Repeat only as needed]

# Suggested route

1. ... because ...
2. ... because ...
3. ... because ...

# At the desk

You can ask for a shelf, pull a work, compare two schools, build a reading stack, visit the counter-shelf, inspect current periodicals, or return to the workbench.
```

## B. Pulled work

```markdown
# Pulled from the shelf: [Work]

**Catalog record:** creator, exact title, year, type/venue
**Role in the field:** ...
**Access basis:** full text / official summary / abstract / excerpts / secondary discussion / metadata

## The problem it tried to solve
...

## Its central move
...

## Conceptual toolkit
- ...

## Evidence or operating experience
...

## What it contributed
...

## Strongest criticism and limits
...

## What aged well and what did not
...

## What to borrow
...

## Reading decision
Read now / read selectively / read later / know about it but skip, because ...

### Borrowed so far
- **Concept:** ...  
  **Source:** ...  
  **Use:** ...  
  **Caveat:** ...
```

## C. Comparison

Use a table when the axes are crisp.

```markdown
# [A] versus [B]

**Shared question:** ...

| Axis | A | B | Why the difference matters |
|---|---|---|---|
| Unit of analysis | ... | ... | ... |
| Core assumption | ... | ... | ... |
| Mechanism or method | ... | ... | ... |
| Preferred evidence | ... | ... | ... |
| Strength | ... | ... | ... |
| Blind spot | ... | ... | ... |
| Best conditions | ... | ... | ... |

## The real disagreement
...

## Implication for the workbench
...
```

## F. Compact state recap

Use when the interaction has become long:

```markdown
## Library receipt so far

**Question map:** ...
**Shelves visited:** ...
**Borrowed concepts:** ...
**Main unresolved disagreement:** ...
**Workbench implication emerging:** ...
**Best next action:** browse ... / compare ... / return
```
